ROLLaWORD BLOG — ADMIN EDITOR STARTER

UPLOAD
Upload the complete contents of this folder into your existing blog folder in the repository.
The main page will be:
  https://www.rollaword.com/blog/admin.html

FILES
- admin.html
- css/admin.css
- js/admin.js

WHAT THIS VERSION DOES
- Provides a simple browser-based writing editor.
- Supports basic bold, italic, headings, quotes, lists and links.
- Saves a working draft in the browser's local storage.
- Previews the draft.
- Downloads the article as a Markdown .md file.

IMPORTANT LIMITATION
This is the writing/editor stage only. It does NOT yet sign users in, check the Firestore blogAuthors collection, upload images, or publish directly to GitHub. The downloaded Markdown file can be added to the repository's pages folder using your current workflow. We will add secure Firebase/GitHub publishing after confirming the Firebase Web App configuration.

Do not upload this folder over or replace the existing public blog renderer files. Add these files alongside them.
