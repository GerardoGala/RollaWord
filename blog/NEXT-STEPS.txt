RollaWord Blog renderer starter

1. This folder is intended to be placed at the root of the existing website
   as /blog/.
2. Do not overwrite any existing RollaWord files.
3. The actual RollaWord site-wide CSS link has intentionally NOT been guessed.
   We will inspect the live homepage and add its exact stylesheet path.
4. markdown-pages.js loads Showdown 1.9.1 from cdnjs.
5. The homepage content is README.md.
6. Article files live in pages/ and are opened with ?page=article-slug.
7. Run through a local web server for testing; opening index.html directly
   with file:// will not work because the renderer uses XMLHttpRequest.
8. This is only the public renderer starter. Admin, authentication, image
   uploads, GitHub publishing, search, categories and SEO improvements are
   separate planned steps.
9. Security: the upstream renderer inserts converted Markdown into innerHTML.
   Before accepting posts from multiple editors, we must add HTML sanitization
   and review how embedded HTML is handled.
10. SEO: the upstream renderer is client-side and uses query-string URLs.
    We'll evaluate the implications before treating it as the final public
    publishing solution.
